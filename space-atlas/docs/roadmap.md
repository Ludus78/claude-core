# Roadmap (12 mois fermes)

Rythme : 5 à 7 h par semaine. Éventuel « acte 2 » après le bilan si la motivation est là.

| Mois | Étape | Contenu |
|---|---|---|
| M1-3 | Globe de départ | Template existant, ISS + quelques constellations, cache CelesTrak |
| M4-5 | Globe v1 | Lancements, couleurs par type d'orbite, infobulles pédagogiques |
| M6-8 | Observatoire v1 | 30 entreprises, carte, filtres |
| M9-11 | Fusion | Les deux modules dans un même site, 2 ou 3 mini-histoires |
| M12 | Bilan | Continuer, pivoter, ou s'arrêter avec un projet fini |

## Règles

- Une étape qui déborde **perd des fonctions** au lieu de prendre du retard.
- Un mois creux est prévu pendant les examens du MBA.
- Pas de comptes utilisateurs, pas d'IA, pas de backend lourd tant que la v1 n'a pas d'utilisateurs.
